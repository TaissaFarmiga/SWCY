## 设计约束

- 适配宽度：320、360、390、430 dp；所有业务页禁止页面级横向滚动。
- 顶部导航：返回、标题、一级高频动作同排；可见高度约 49 px。
- 圆形：无文字的返回、删除、图表、历史等单一图标动作。
- 胶囊：主操作、分段选择、状态切换、短文字动作。
- 圆角方形：更多面板中的并列功能；只保留一层更多面板，不套二级菜单。
- 可见按钮高 36–40 px；触控热区用透明外扩保持约 44 px，不用大面积空白换可点性。
- 统一半透明材质、内高光、细边框、模糊背景、轻阴影和按压反馈；深色模式同步。

## 问题、方案、验收条件

| 问题 | 实施方案 | 验收条件 |
| --- | --- | --- |
| 三等切普通界面晃动，无震动 | 等级选择使用等宽胶囊分段，不改变容器高度；有读数时禁止原地改变规则；切换成功调用 Capacitor Haptics，浏览器回退 `navigator.vibrate` | 切换前后头部和等级条高度不变；原生设备有轻触反馈 |
| 返测依赖测点名称加“返” | 路线和测站保存独立 `direction`；点击一次“开始返测”后，后续新站自动继承返测；列表只在往返边界显示一次说明 | 不需逐站标注；导入旧数据兼容；成果仍能区分往返 |
| 纵断面、成果表、轨迹占空间 | 成果表、纵断面改为头部圆形图标；低频轨迹进入唯一更多面板 | 320 dp 下头部按钮完整；无第二层菜单 |
| 测流、水准页功能按钮位置不一致 | 两页统一为返回、单行标题、直接动作、更多按钮的同排结构 | 头部约 49 px；无顶部空白；左右规则一致 |
| 间视黑红面显示不全 | 间视读数使用自适应双列，输入框不设脆弱固定宽度；内容和单位分层 | 320 dp 下黑面、红面和四位读数完整，无横向滚动 |
| 加间视、加测站过高且突兀 | 改为 36–40 px 液态玻璃胶囊或圆形图标；删除操作使用红色玻璃态二次确认 | 视觉高度收窄；触控热区约 44 px；危险操作不误触 |
| 测流结果及其他页面行高过高 | HUD、卡片、结果行、元数据、站卡间距统一收紧；保留字段分组和可读层级 | 首屏显示更多有效字段；文本、单位、状态不重叠 |
| 流速数字显示不全 | 流速输入改为弹性宽度并保留 16 px 字号，避免 iOS 自动放大；长小数由 Android 自动测试写入 | 320 dp 下 `12.345678` 可写入、可见、无页面横向滚动 |
| 电子气泡无法居中 | 方向与重力双源、屏幕旋转换算、中值和低通滤波、校准归零、0.10° 显示死区；气泡位移限制在靶盘内 | 零读数映射靶盘几何中心；极端读数不越界 |
| 气泡容错过严 | 使用滞回：0.50° 进入中心、0.70° 离开中心，减少阈值抖动 | 临界读数不会反复闪烁；说明文字与算法一致 |
| 未发现 GPS 请求 | Android 声明粗略、精确定位；新增测站时检查并请求 Capacitor Geolocation 权限；拒绝后明确提供无定位建站 | 首次建站触发系统权限；拒绝不会阻断外业记录 |

## 举一反三整改

- 页面安全区：顶部使用真实 `safe-area-inset-top`，不额外强制 16 px 空白。
- 窄屏头部：标题允许截断，动作不可挤出视口；水准轨迹降为低频菜单项。
- 菜单层级：测流模板直接显示为横向条目；水准导入、导出、主题、设置全部在同一面板。
- 输入一致性：测流垂线、岸边、水准前后视、间视字段统一紧凑圆角输入样式。
- 删除一致性：测线、测站、路线删除都保留二次确认，视觉危险色不再使用实心突兀色块。
- 横竖屏与离线：Android 自动测试覆盖 320×568、横竖屏切换、离线重建、持久化和分享面板。
- 权限降级：GPS、方向、重力数据不可用时给出明确状态，不伪造坐标或传感器数据。

## 自动验收证据

- 10 轮全量检查入口：`npm run test:full:10`。每轮执行 typecheck、lint、业务测试、生产构建，共 40 个门禁；结果写入 `verification/mobile-ux-v1.10.28/full-verification-10-rounds.json`。
- 5 轮 Android 冒烟压力入口：`npm run test:android:all:5`。每轮使用一次性 API 35 AVD，执行冷启动、完整冒烟、商店截图、压力测试；最终 JUnit 和截图哈希写入 `verification/mobile-ux-v1.10.28/android-final/`。
- 浏览器实测：320、360、390 px 已检查头部、菜单、输入和页面级溢出；430 dp 由 Android 设备配置继续覆盖。

## 发布与回退边界

- 正式 APK/AAB 只接受正式 keystore。缺少 `HYDRO_KEYSTORE_*` 或 `android/keystore.properties` 时，发布脚本必须失败；不以 debug key 伪装发布。
- 正式发布完成后，回退使用 `npm run build:android:forward-rollback -- --target <备份标签> --version <更高版本>` 生成更高版本号的前向回退包。
- GPS、震动、IMU 最终验收必须使用物理 Android 设备。模拟器和桌面浏览器通过只证明权限路径、降级逻辑及 UI，不等同真实硬件验收。
